# 리디브(redev) — 서울 재개발 구역·매물 플랫폼 MVP

재개발닷컴 / 갈타맵 / 재개발뷰의 강점을 합친 정비사업 전문 플랫폼 MVP.

## 수익 구조 (3-트랙)

| 트랙 | 요금 | 내용 |
|---|---|---|
| 🔍 구역 실거래가·사업단계 | **무료** | 유입 트래픽용. 지도 경계 폴리곤, 유형·단계 필터, 실거래 배수 분석 |
| 🏢 중개사 매물 등록 | **베타 무료** | 지금은 결제 없이 바로 등록(정식 오픈 시 단건 9만원 / 월 29만원 예정) |
| 🔓 매물 정보 | **무료** | 매매가·기보증금·**초기투자금**·임대사업자 승계·토허제 여부까지 목록에서 바로 공개(열람권 결제 없음) |

## 주요 화면

- `/` **구역 탐색기**: **카카오맵(JS SDK)** 위에 **서울시 정비구역·역세권·장기전세 전수 2,179곳** 경계 폴리곤(10분류 색상, 단일 Canvas 오버레이), 구역명·지번 별칭·사업유형 검색, 클릭 시 상세 패널
  - **주소 검색 → 소속 정비구역 자동 판별**: 검색창에 `신림동 362-32`·`테헤란로 152`처럼 지번·도로명을 치면
    카카오 `Geocoder.addressSearch`(결과 없으면 `Places.keywordSearch`, `서울 ` 보정)로 서울 주소 후보를 함께 보여주고,
    고르면(엔터면 첫 후보) **전체 2,179구역 폴리곤에 광선교차(Point-in-Polygon)** 판정을 한다 —
    Polygon·MultiPolygon·구멍(hole) 처리 포함. 주소 위치에 핀+말풍선을 찍고
    **진행 중 구역이면 `✅ ○○구역 포함` + 그 구역 선택·상세 패널**, 겹친 구역이 있으면 겹침 목록도 보여준다.
    **준공 구역**이면 `🏁 준공 완료된 ○○구역 내 주소`로 알리고 준공 토글을 자동으로 켜며,
    **경계 미고시 후보지**(사당21구역 등 점 표시) 250m 안이면 `⚠️ … 인근 주소`로 안내한다.
    **구역 밖**이면 판정 문구 없이 그 위치를 조용한 슬레이트 핀(주소 한 줄)으로만 찍고,
    카드에는 가까운 구역 1~3곳(직선거리 m/km, 클릭 시 이동)만 둔다.
    핀은 `핀 지우기 ✕`로 지운다. 검증: `scripts/verify-address-search.py`
  - **지도가 화면 전체** (재개발뷰·네이버지도 방식): 헤더 52px만 남기고 지도가 뷰포트를 채운다. 검색·필터·범례는 지도 위에 떠 있는 카드(접기 가능), 구역 상세는 데스크톱 오른쪽 드로어 / 모바일 아래 시트
  - **휠 줌·드래그 중에도 경계가 지도에 정확히 붙어 있다 (프레임 지연 0)**: 배율을 추정하지 않는다.
    카카오는 자기 벡터 레이어(SVG)의 `left/top/width/height` 를 **매 프레임 JS 로** 바꾸므로,
    같은 레이어에 아주 작은 투명 사각형 두 개(기준점)를 그려 두고 그 **실제 화면 좌표**에서 지도
    변환(배율·기준점)을 그대로 읽는다. 카카오가 그 레이어를 갱신하는 그 순간을 `MutationObserver`
    로 잡아 같은 프레임의 페인트 전에 다시 그리므로, 줌 중심이 커서여도·관성 드래그여도 경계가
    지도에서 떨어지지 않는다. 검증: `scripts/verify-zoom-sync.py` (휠·버튼·커서 치우친 줌·드래그·
    플릭·스카이뷰·깊은 확대·넓은 축소 전 시나리오에서 **2px 이내 100%**, 최대 오차 1.2px)
  - 카카오 기본지도라 **지하철 출구번호·역명·건물명·지번**이 그대로 나온다 (별도 지하철 레이어 불필요)
  - 지도 위 토글: **스카이뷰**(위성+라벨 HYBRID) · **지적편집도**(USE_DISTRICT) · **노후도**(건물 연식) · **준공 포함(357곳, 기본 OFF)** · 확대/축소
  - **노후도(건물 연식) 오버레이** — 국토부 **GIS건물통합정보**(브이월드 국가중점 WFS `dt_d010`)의 **건물별 사용승인일**로
    개별 건물을 색칠한다: **30년 이상**(진한 빨강) · 20~30년 · 10~20년 · 10년 미만 · 연식 미상(회색).
    · 지도 아래 툴바의 `노후도` 토글 — 켜면 지도 하단에 구간별 범례와 **지금 칠해진 건물 동수**가 뜬다
    · 화면을 0.005° 격자 타일로 나눠 필요한 타일만 서버 라우트(`/api/building-age`)로 받는다(인증키는 서버에만 — `VWORLD_API_KEY`)
    · 받은 타일은 구간별 **Path2D 하나로 합쳐** 두고 지도 변환을 `ctx.setTransform` 으로 걸어 칠한다 → 건물 수천 동이어도 프레임당 fill 5번
    · 배율이 멀면(카카오 레벨 5 이상) "더 확대하면 건물별 연식이 칠해집니다" 안내만 보여 준다(타일·요청 폭증 방지)
    · 검증: `scripts/verify-building-age.py` (토글·범례 동수 합계·캔버스 픽셀 색·끄면 사라짐)
  - **관리자 모드(`?admin=1`)** — 대표님 전용 **지도 위 구역 그리기·경계 수정**. 일반 방문자 화면은 이 모드가 꺼져 있으면 기존과 완전히 같다
    · **진입**: 주소 뒤 `?admin=1` (한 번 열면 `localStorage['redev.admin']` 에 기억돼 이후엔 주소에 없어도 열린다). `관리자 모드 종료 ✕` 를 누르면 플래그와 주소 파라미터가 지워진다
    · **새 구역 그리기**: 지도(카카오맵)를 탭해 꼭짓점을 찍고 **실시간 면적(㎡·평)** 을 지도 배지·패널·도구 막대에서 확인, `실행취소`(마지막 점) · `완료` · `취소`. 첫 점을 다시 탭해도 완료된다
    · **경계 수정**: 구역을 고른 뒤 `경계 수정` → **꼭짓점 드래그**(44px 터치 핸들, iPad 손가락 대응), **변 가운데 `+`** 로 점 추가, **`✕` 배지·우클릭**으로 삭제. 공식 고시 구역도 고칠 수 있고, 저장하면 그 구역의 **경계 보정본**(`replacesZoneId`)이 된다
    · **저장**: `구역명 · 사업유형(신통기획/모아타운/일반재개발/도공복/민간도심복합(성장거점형)·(주거중심형)/가로주택/역세권/장기전세/기타) · 추진단계 · 자치구 · 비고` 입력 → **`localStorage` 즉시 저장**(새로고침해도 유지, 관리자 모드에서만 지도에 그려짐), 목록에서 수정·삭제
    · **내보내기**: `JSON 다운로드` · `클립보드 복사` — GeoJSON FeatureCollection(`zones.geojson` 과 같은 properties) + `ringLatLng`(`scripts/data/official-*.json` 과 같은 **[위도, 경도]**). `replacesZoneId` 가 있으면 공식 도형을 대체하는 보정이라는 표시다
    · 검증: `scripts/verify-admin-draw.py` — 데스크톱 마우스 + **아이패드 1024×768 터치**(탭으로 점 찍기, 지도 끌기는 점을 만들지 않음, 핸들 터치 드래그), 면적 교차검증(신림1구역 고시 223,201㎡ ↔ 그린 도형 오차 0.6%)
  - 카카오 키·도메인이 준비되지 않으면 **자동으로 Leaflet/OSM 지도로 폴백**(지도가 비지 않게, 지도 위에 작은 안내)
  - 재개발닷컴 스타일: 유형(일반재개발/신통기획/모아타운/도공복/가로주택/소규모/**역세권/장기전세**)·단계 필터 칩, 등록매물수·최저가·최저 초기투자금 뱃지
    · 유형 칩은 서울시 전수 레이어에도 걸린다 — 고른 유형만 지도·범례에 남고, 검색과 주소 판정은 필터와 무관하게 전체를 본다
  - 전수 구역 클릭 → 서울시 고시 데이터(구역명·자치구·사업유형·추진단계·고시면적 ㎡/평·경계 도형·기준일)
  - 이어서 **최근 실거래가(국토부)** 섹션 — 구역이 걸치는 법정동에서 최근 3·6개월 실제 신고 거래를 보여준다
    (유형 필터 전체/아파트/단독·다가구/연립·다세대, 거래일·전용·대지 ㎡와 평·층·준공년도·거래금액(억/만원)·**평당가**).
    · **`구역 내`(기본) / `법정동 전체` 두 탭** — 국토부는 좌표를 주지 않으므로, 거래의 지번 주소를 카카오 주소검색으로
      **지오코딩**해 좌표를 얻고 그 점이 선택한 구역 폴리곤 안에 드는지(`pointInRing`) 판정한다.
      그래서 한남3·4·5구역이 각각 **서로 다른 목록**을 보여준다(2026-11-18 기준 6개월: 한남3 0건 · 한남4 5건 · 한남5 9건).
    · 구역이 걸치는 법정동은 구역 안쪽 표본점(격자 + 안쪽으로 당긴 꼭짓점)의 역지오코딩으로 모아
      `GET /api/transactions?gu=…&dongs=한남동,동빙고동,…` 로 함께 조회한다(한남5 → 한남동·동빙고동·주성동·서빙고동·보광동).
    · 지번 좌표는 지번 단위로 메모리 + `sessionStorage` 에 캐시하고 6건씩 묶어 최근 거래부터 판정하며 진행률을 보여준다
      (같은 구역을 다시 열면 즉시 표시). 단독·다가구는 국토부가 지번을 `1**`처럼 가려 판정할 수 없어 '법정동 전체'에서만 보인다.
    · '구역 내 0건'이면 크래시 없이 안내와 함께 **[법정동 전체 보기]** 버튼을 준다. 계약 해제(`cdealType=O`)는 '해제' 배지로 따로 보여준다.
    · 검증: `scripts/verify-zone-tx.py` — 한남3·4·5 비교, 탭 전환, 경계 미고시 구역, 단독·다가구 안내, 콘솔 오류 0건.
  - 범례에 유형별 실제 구역 수(일반재개발 674 · 가로주택 718 · 역세권 196 · 소규모 194 · 장기전세 159 · 신통기획 110 · 모아타운 94 · 도공복 34)
    · **역세권** = 역세권활성화·청년안심주택(주황), **장기전세** = 장기전세주택·미리내집(마젠타) — 상세 패널의 ‘사업유형’에 소분류가 그대로 나온다
  - **공식 구역명·지번 별칭**: `사당동 419-1`로도 `사당15구역`으로도 같은 구역이 검색된다(서울시 고시·정보몽땅으로 확인한 이름)
  - **구역계 미고시 후보지**(예: 사당21구역 — 2026-05-07 후보지 선정)는 경계를 지어내지 않고 지도에 **점**으로 표시
  - 재개발뷰 스타일: **실거주 의무 / 토허제 적용** 뱃지, **예상 입주 구간**
  - **매물 연결**: 매물이 있는 구역은 지도 중심에 **`🏠 매물 N`** 배지(z-index 100 레이어, 카카오·OSM 공통).
    배지를 누르면 그 구역 상세가 열리고, 오른쪽 패널 맨 위(고시 데이터 아래·실거래가 위)에 **`검증 매물 N건`** 카드가 붙는다
    (매매가·기보증금·**초기투자금**·임대사업자 승계·토허제·특징·중개사). 필터 바에는 **`🏠 매물 있는 구역` · `임대사업자 승계` · `실거주(토허제) 없음`** 칩이 있다
  - 갈타맵 스타일 상세: 사업개요(추정비례율·세대수·시공사), 추진경과 타임라인(고시/공고 링크 자리), 실거래 테이블(**대지지분·공시가 배수**·유형별 추이), 구역 내 매물 비교 컬럼(매매가·초기투자금·추정 권리가액·불하금 유무·참고순위)
- `/listings` **검증 매물**: 정식 검증 매물(`src/data/verified-listings.json`) + 샘플 + 이 브라우저 등록 매물을 합쳐 카드로 보여준다.
  · 필터: **검증 매물만 · 임대사업자 승계 · 실거주(토허제) 없음**, 정렬: **초기투자금 · 매매가 · 최근 등록** (기본 = 초기투자금 낮은 순)
  · 구역 이름을 누르면 `/?zone=<구역 id>` 로 메인 지도에서 그 구역 상세(경계·실거래가·매물 카드)가 열린다
  · **비교함**(최대 4건): 매매가·기보증금·초기투자금·전용·대지지분·임대사업자·토허제·특징을 한 표에서 나란히
- `/register` **중개사 매물 등록 (베타 무료)**: 요금제·모의 결제 단계 없이 **바로 입력**한다.
  · 구역은 `zones.geojson` 의 **2,289곳 전체**에서 실시간 검색(`상도23`·`신림1`·`자양동 10`·`한남4`)해 고른다
  · 입력: 매물 종류·호수/타입·**매매가·기보증금**·감정평가액(프리미엄 자동)·불하금·**전용면적·대지지분**·**임대사업자 승계**·**토허제(실거주)**·특징 메모
  · **초기투자금 실시간 계산**(매매가 − 기보증금 + 불하금) — 예: 7.8억 − 2.77억 = 5.03억
  · 등록하면 `localStorage(redev.customListings.v1)` 에 저장돼 **메인 지도 배지·상세 카드·매물 목록에 즉시 반영**(`redev:listings-changed` 이벤트)
  · 구역 상세의 `매물 등록하기` 로 들어오면(`/register?zone=<구역 id>`) 그 구역이 미리 선택된다
  · `JSON 다운로드/복사` 는 `verified-listings.json` 과 **같은 모양** — 받은 파일을 `src/data/verified-listings.json` 에 넣으면 모든 방문자에게 보이는 정식 매물이 된다
  · 검증: `scripts/verify-listings-map.py`
- `src/data/verified-listings.json` — **정식 검증 매물**(현재 1호: 상도23구역 다원씨앤아이 404호, 매매 7.8억·기보증금 2.77억·전용 29.175㎡·임대사업자 승계 필수)

## 기술 스택

Next.js 16 (App Router, TypeScript) · Tailwind CSS 4 · **카카오맵 JavaScript SDK**(기본 지도) + Leaflet 1.9/OpenStreetMap(폴백) · Supabase(Postgres) 준비

> **지도 설정**: `.env.local` 의 `NEXT_PUBLIC_KAKAO_MAP_APP_KEY` 에 카카오 **JavaScript 키**를 넣고,
> 카카오 Developers → 플랫폼 → Web 사이트 도메인에 배포 주소(`https://redev-platform-iota.vercel.app`)와
> 로컬 주소(`http://localhost:3100`, `http://localhost:3000`)를 등록한다.
> 키가 없거나 SDK가 뜨지 않으면 자동으로 OSM 지도로 폴백한다(Admin 키·REST 키는 넣지 말 것 — 서버 전용 비밀 키).

## 실행


## Supabase 배포

   (tables: `zones`, `transactions`, `brokers`, `listings`, `unlocks`, `broker_subscriptions` + RLS 전면)
2. `.env.local`에 `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` 입력
3. Vercel: GitHub 저장소 연결 → 환경변수 동일 입력 → Deploy

## 공공 데이터 연동

- **실거래가(적용됨)**: 국토부 실거래가 공개 API `https://apis.data.go.kr/1613000/`
  · 아파트 매매 상세 `RTMSDataSvcAptTradeDev` · 단독/다가구 매매 `RTMSDataSvcSHTrade` · 연립/다세대 매매 `RTMSDataSvcRHTrade2`
  · `LAWD_CD`(자치구 5자리) + `DEAL_YMD`(YYYYMM)로 **구 단위 월별 조회** → 서버에서 법정동·유형으로 걸러 `GET /api/transactions`가 내려준다
  · `GET /api/transactions?gu=용산구&dongs=한남동,보광동&months=6` — `dongs`(쉼표·가운뎃점 구분, 최대 8개)로 여러 법정동을
    한 번에 받는다. 예전 `dong` 파라미터도 그대로 동작한다. 구역 경계 안팎 판정은 클라이언트가 한다(이 라우트는 좌표를 모른다)
  · 서버 캐시 **(구·월·유형) 1시간** — 같은 구의 다른 구역을 눌러도 국토부를 다시 부르지 않는다(콜드 1.3초 → 캐시 0.04초)
  · `MOLIT_API_KEY` 는 **서버 전용**이다. `NEXT_PUBLIC_` 접두사를 붙이면 브라우저에 노출되므로 금지
  · 연립·다세대는 **신버전 `RTMSDataSvcRHTrade2`**로 부른다(2026-11-18 교체). 구버전 `RTMSDataSvcRHTrade`는
    이 키로 호출하면 `returnReasonCode 30`(등록되지 않은 서비스키)이 와서 늘 미연동으로 떴다.
    신버전은 건물명 `mhouseNm`·전용면적 `excluUseAr`·대지권면적 `landAr`·지번 `jibun`을 그대로 주고,
    화면에는 건물명(삼지빌라 등)으로 표시한다.
  · **Vercel 배포에 적용하려면** 프로젝트 → Settings → Environment Variables 에 `MOLIT_API_KEY` 를 추가해야 한다.
    키가 없으면 화면은 크래시 없이 "서버에 국토부 API 키가 아직 없습니다" 안내를 보여준다.
